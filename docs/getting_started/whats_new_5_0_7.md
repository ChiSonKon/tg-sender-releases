> 写给付费客户的人话版。
## 改进
- **发不出去的目标只失败一次，不再让账号轮流重试**：对方开了「付费消息」、对方的隐私设置不允许陌生人私信、或对方账号已注销，这些都是**对方的设置**，换哪个账号都发不出去。以前软件会让每个账号都对同一个目标再试一遍（日志里连续刷十几条同样的失败），现在只记一次失败并写明原因，立刻处理下一个目标。「多对一」策略下同一个目标也不会被每个账号各发一次。
- **「双向 / 隐私限制」不再混为一谈**：以前对方隐私设置导致的失败也被写成「触发双向限制」，容易让人以为自己的账号双向了。现在分开：
  - 对方隐私设置 / 付费消息：日志写明「这是对方的设置，不是你的账号受限」，不重试、不换号；
  - 账号真的被 Telegram 限制给陌生人发消息（PeerFlood）：这个账号本次发送不再使用，自动换下一个账号；所有账号都被限制时任务自动停下，不再一直撞墙。账号的状态仍以「检测状态」的核实结果为准，发送时的异常不会改动账号状态。
- **风控额度一眼能找到**：软件右上角新增常驻的「🛡 风控额度」按钮，旁边的小标签显示当前模式（默认绿色、自定义橙色、已关闭红色），点一下直达「设置 → 账号风控额度」；风控阶段那一列的提示也写明了去哪里放开。发送结束后如果有账号被额度拦住，会弹出说明——这是软件自带的保护、不是 Telegram 的限制、账号状态没有变——并带「去调整账号风控额度」按钮。（以前只在日志里写一句，很多人找不到设置，还以为是软件不好用。）额度怎么设仍由你决定：保持默认、自定义或关闭，软件不强制。
- 额度被拦的账号不再被当成 Telegram 的「陌生人私信限制」处理：不再等几秒重试，直接换下一个账号，日志写明是风控额度。
- **申诉全自动**：冻结、双向受限的申诉都由软件自动走完，不用再自己点链接：自动点「这是个错误 / 确认提交」，自动回答声明题，自动提交申诉说明。遇到 Telegram 的**人机验证**时，软件会自动用你电脑上的浏览器（优先 Chrome）打开验证页，页面上的验证会自己通过（不用点），通过后软件自动接着申诉并关掉浏览器；自动没通过才会重新打开页面请你手动完成，完成后点「这一批已完成，继续」。需要**你自己的姓名 / 邮箱**时（第一次填写后软件记住，以后自动带上；不填则用默认候补资料）才会问你。声明题和申诉说明只陈述本机发送记录里有依据的事实，软件不再随机编造姓名、邮箱。AI Agent 接口 `tg_spambot_appeal` 新增 `action=auto`，同样全自动。
- **申诉结果如实说**：以前只要 SpamBot 回复里出现「review」之类的词就判「成功」，结果在「要不要提交申诉？是 / 否」这一步就停下并报成功，其实什么都没提交。现在只有 SpamBot 给出陈述性的回复（不是提问、也没有要你选的按钮）才算「已提交」；汇总写成「SpamBot 回复表示已提交 / 无限制」，是否真的解除要之后用「检测状态」确认。
- **申诉提交后不会立刻解封，请耐心等**：「已提交」只表示 Telegram 官方收到了你的申诉，之后要等官方复核，通常要等几个小时到一两天（官方没有承诺时限），双向受限和冻结都是这样。等待期间**不要重复申诉**（重复提交不会让官方复核更快）；过一阵子用「检测状态」核实是否已解除。
- **申诉时的人机验证更省心**：遇到 Telegram 的人机验证，软件会自动用你电脑上的浏览器（优先 Chrome）打开验证页，页面上的验证通常会自己通过，通过后软件自动接着申诉并关掉浏览器；自动没通过才会重新打开页面请你手动完成。弹出的浏览器窗口请不要手动关闭。
- **发送过程中账号被风控：自动跳过，不再去申诉**：群发 / 私信中某个账号被限制，软件只在本次发送里不再使用它，继续用其余账号，结束时在日志里列出被跳过的账号及原因；**不会**因此自动发起申诉（申诉只在你主动点「申诉」时进行），也不会仅凭一次发送失败就改账号状态——是否受限请用「检测状态」核实。AI 炒群里某个账号发言失败时同样只是本次跳过它，不再自动申诉、不再改状态。
- **发送中可以暂停 / 继续，也可以随时排除账号**：群发页新增「⏸ 暂停 / ▶ 继续」，暂停后点继续从暂停的地方接着发，不用停止再从头开始；新增「🚫 排除账号」，发送过程中勾选几个账号（比如刚被双向的号），它们从下一条开始不再参与，任务不用暂停，其余账号继续发。
- **私信自动回复不再把老客户又回复一遍**：固定话术模式下，同一位客户 24 小时内只自动回复一次（可在自动回复页改小时数，0 = 每条都回），记录保存在本机，停止 / 重启后依然有效；另有一项「重启后不回复停止期间收到的旧消息」（默认开），重新启动后不会把停止期间客户发来的消息又回复一遍。
- **批量踢出其他设备**：「安全与格式转换 → 已登录设备」新增「批量踢出所有在线账号的其他设备（只保留本软件）」，一次处理本软件里所有在线账号，不用再一个号一个号点。每个账号踢完会重新读取设备列表核实，真的只剩本软件才算成功；没连接的账号跳过、不动它；刚登录不满 24 小时的账号 Telegram 不允许踢，表格里会写明原因。
- **Mac 包的签名更严格**：打包时先逐个签内部文件，冒烟自检并清理之后重新签一遍并校验，装进 dmg 的那份再校验一次，签名有问题的包不会发出来（用来解决个别 Intel Mac 提示「已损坏，无法打开」）。**已下载的旧包**如果还是提示「已损坏」，在终端执行 `xattr -cr` 和 `codesign --force --deep --sign -` 两条命令即可（见 DISTRIBUTION_GUIDE）。（这一条没有在真实 Mac 上验证，请反馈是否解决。）
- 服务器端：同一台镜像克隆出来的多台电脑共用硬件标识时，授权不再互相抢占，减少「设备公钥与历史记录不一致」（5.0.7 服务端部分已先于客户端上线）。

## 注意
- 对方的隐私设置是「仅联系人可发」时，Telegram Premium 账号可以绕过，但软件对这类目标只用当前账号试一次；想用 Premium 号去发，请单独选 Premium 账号。
- 付费消息（需要给对方付星标才能发）软件不处理。
