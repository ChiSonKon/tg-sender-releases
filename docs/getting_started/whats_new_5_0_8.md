# 🆕 v5.0.8 更新说明

> 5.0.7 的功能请看 [v5.0.7 更新说明](whats_new_5_0_7.md)。

> 写给付费客户的人话版。

## 改进
- **启动更快、更顺**：优化了软件的启动进程，打开软件到看到主界面的时间明显缩短，启动过程也更流畅。
- **全新图标**：桌面、任务栏和软件里的图标换成了新设计的白猫与纸飞机，日间、夜间两种主题下都协调好看。（Windows 有图标缓存，升级后如果桌面图标还是旧的，注销重新登录或重启一次电脑即可。）
- **申诉填写更贴近真实账号**：申诉时 SpamBot 会问「大约哪一年注册」，软件现在按账号的用户 ID 自动估算注册年份，老账号不会再统一答成同一个年份；发现途径、日常使用、申诉说明也会在多套模板里变换，不再每个账号都发一模一样的话。你自己在配置里填过的资料仍然优先。
- **有些限制没有申诉入口，软件会如实告诉你**：如果 SpamBot 对某类限制（例如因公开内容被举报而限制建频道、在公开场所发言）只给出一个邮箱让你自己写信（abuse@telegram.org），软件不再弹出要你「回答」的输入框，而是在日志里明确写明「官方对这类限制没有申诉入口，需要你自己发邮件，软件不会替你发」。
- 申诉确认框里的说明文字改成与实际行为一致：声明题默认走「争议复核」，可在配置里改为按本机发送记录选择。

## 注意
- 申诉提交后不会立刻解封，请耐心等待官方复核，期间不要重复申诉，用「检测状态」核实结果。
- 同一批账号不要在两台电脑（或两个软件）里同时登录：同一个 session 在两处同时使用会被 Telegram 作废，需要重新登录。
