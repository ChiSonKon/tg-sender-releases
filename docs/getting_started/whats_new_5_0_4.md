# 🆕 v5.0.4 更新说明

> 5.0.3 的功能请看 [v5.0.3 更新说明](whats_new_5_0_3.md)。（本版本含 Windows 与 macOS Apple 芯片；macOS Intel 暂无新包，仍为 5.0.1。）

## 一、私密群邀请链接
- 把私密群的邀请链接（`https://t.me/+…`）作为目标群时，以前会提示「找不到目标群」，群发、采集、炒群、剧本回放都受影响。现在账号已在群里就能正常识别；账号还没加入时会明确提示「请先让账号加入」，链接失效也会说明。邀请链接只用来识别账号已经在里面的群，不会替账号加入。

## 二、资料修改 · 一键伪装
- 新增**指定任意目标账号**（每行一个 `@用户名` / 链接 / 用户 ID），直接取这些账号的名字、用户名、简介、头像；目标账号和目标群可以只填一个、也可以都填。
- 在表格里**点选一个或多个要改资料的账号**（Ctrl / Shift 多选）：伪装资料只填进选中的行，「保存并应用修改」也只修改选中的行。
- 目标群成员名单被隐藏的群，改读近期发言的人；频道改读它的评论群；一个账号进不去的群自动换其它已选账号；全部失败时逐群说明原因。
- 成员简介现在能正确取到。

## 三、更流畅
- 电脑较慢时自动关闭背景动画；「设置 → 界面与性能」里可选「自动 / 始终开启 / 关闭」。
- 关键词线索表、账号表等大表格的刷新大幅提速（线索表 1000 行重建由约 55 秒降到 0.3 秒）。
- 批量加群等页面出现很长的提示时，左侧面板不再被挤乱。

> 说明：以上在自动化测试里验证过，未在真实 Telegram 账号上逐项验证；卡顿改善未在客户电脑上复测，若仍觉得卡，请提供日志反馈。
