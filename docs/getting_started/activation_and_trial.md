## 一、免费试用

- 新电脑第一次启动会自带一段**免费试用时间**（目前约 **3 小时**，具体剩余时间以软件界面顶部显示的倒计时为准）；
- 每台电脑的免费试用**只有一次**；
- 试用到期后功能会暂停使用，**不会删除你的账号和数据**，激活授权后可继续使用。

## 三、两种购买方式

### 方式 A：软件内购买（推荐）
1. 试用到期时弹出的窗口里点 **「购买」**（或在软件里打开「购买授权」收银台）；
2. 选择套餐 → 选择转账网络（TRON / BSC / TON / Solana / Polygon / Ethereum 等 USDT 网络）；
3. 按页面显示的**金额和地址**转账（订单有倒计时，请在倒计时内完成）；
4. 到账后卡密会**自动发放并自动激活**，无需手动输入。

### 方式 B：官方 Telegram 机器人
打开 [@oxbaimaobot](https://t.me/oxbaimaobot)，选择套餐并付款，付款完成后机器人会把卡密发给你，再按下面的步骤激活。

## 四、激活卡密

1. 打开软件，点击窗口左下角的 **「🔑 激活 / 找回卡密」**；
2. 在输入框粘贴卡密（格式类似 `WC-XXXX-XXXX-XXXX-XXXX`，也可以直接复制后让软件自动识别剪贴板）；
3. 点 **「🔑 激活授权码」**，看到「授权有效」即成功；
4. **忘记卡密？** 同一窗口点 **「找回我的卡密」**，可以找回在这台电脑上买过或激活过的卡密。

## 五、续费、换机与注意事项

- **续费**：临近到期软件会提醒；通过官方机器人购买的卡密，机器人也会在到期前提醒并提供「立即续费」。续费会在原有到期时间上叠加。
- **换电脑**：在新电脑上用同一卡密激活即可（受套餐席位数限制）。
- **卡密请自己保管**，不要发给别人；遇到被盗用请立即联系官方客服。
- 激活需要联网；偶尔断网时软件会按服务器授予的有效期继续运行一段时间，恢复网络后自动续期。
- 遇到「激活失败 / 提示设备已使用」等问题，请把软件里复制的诊断信息发给客服。
