# 🆕 v5.0.6 更新说明

> 5.0.5 的功能请看 [v5.0.5 更新说明](whats_new_5_0_5.md)。

## 新增
- **多语言**：界面新增「繁體中文」和「English」。第一次打开按电脑的语言自动选择，也可以在「设置 → 界面与性能 → 界面语言」随时切换，立即生效，不用重启。英文译文由 AI 起草，个别用词可能不够地道，欢迎反馈。
- **账号分组**：在「账号管理」点「🏷 分组」建组（比如「采集号」「发送号」），把选中的账号放进去；一个账号可以在多个组。采集、群发、私信等页面的账号选择里多了「按分组选择…」，一键只选这一组。删除账号时会自动从分组里移走。
- **采集更清楚、更快**：采集时每个群一行实时进度（哪个账号在读、读到多少）；每个群读完，成员立刻进列表，不用等全部结束。群比账号少时，闲置账号会按时间段分摊同一个大群的「最近发言人」，不再 50 个账号只有几个在干活。采集结果里的用户名带上了 @。
- **目标分类真正并发**：可以设置「N 个账号同时解析」，每个账号一次只解析一条（避免被限流），分类过程中结果边出边显示。
- **给 AI Agent（MCP）**：`tg_list_accounts` 新增 `group` 参数，可按分组查看账号，返回每个账号所在的分组；分组在 MCP 里只读（增删分组在软件里做）。

## 改进
- 侧边栏「AI 炒群」改名「全能炒群」；页面顶部「AI 智能生成 / 预设剧本回放」切换按钮改成选中高亮、与「统一群发」同样的样式。
- 预设剧本回放新增「📥 从参考群聊天生成剧本」：读取参考群最近的聊天，自动整理成剧本文件（多个群一次生成），只读取、不发送。
- 修复：切换语言时侧边栏文字不跟着变。
- 炒群「预设剧本回放」的「转发非任务账号的发言」新增「不转发机器人发的消息」（默认勾选）：转发群里不再被机器人刷屏。
- 「购买账号」按钮挪到了「全部连接」左边，不用再点开「更多」。
- 登录账号、导入 Session 之后都会提醒给账号配固定的静态代理（选了「7 天内不再提示」除外）；提醒里的客服链接可以直接点开；去掉了「复制客服链接」按钮；说明只讲稳定的静态 IP。
- 修复：采集页的并发数保存后重新打开被改回 3。

## 注意
- 账号分组存在软件配置里，不随 Session 文件备份；换电脑要连配置一起迁。
- 闲置账号分摊大群、多账号并发分类的提速在真实 Telegram 下还没验证，效果取决于账号数量和 Telegram 的限流。
- 英文界面下部分页面比较宽，需要横向滚动；后续版本会继续调整。
