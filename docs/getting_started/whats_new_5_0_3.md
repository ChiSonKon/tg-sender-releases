# 🆕 v5.0.3 更新说明

> 5.0.2 的功能请看 [v5.0.1 更新说明](whats_new_5_0_1.md)。（本版本为 Windows 版；macOS 暂无 5.0.3 新包，仍为 5.0.2。）

## 一、「按目标开始」流程更顺手
- 采集、分类、发送做完一步，页面顶部会问「要进入下一步吗」；不点就留在当前页。
- 一键把采集名单带去分类 / 私信，把筛出的真人用户带去私信：只追加到下一页的输入框（去重、不覆盖你已填的内容），不会自动开始。采集页、分类页也有常驻按钮。
- 步骤条新增「跳过这步」，不需要的步骤可以直接跳过。

## 二、代理绑定可以解除
- 「释放失效账号的绑定」：一键释放被封 / Session 失效 / 已删除账号占着的代理名额（离线、连接失败这类没连上的账号不会被当成失效）。
- 「解除选中账号的绑定」：手动解除；仍在线的账号下次重连会改走本机网络，软件会先提示确认。
- MCP：`tg_manage_proxies` 新增 `unbind`（默认只预览）。

## 三、炒群新增「预设剧本回放」
- 导入自己编辑的多角色话术文件，多个账号按剧本在群里演：`[rN]` 引用账号最近发出的消息，图片按路径或文件名检索，`<时:分:秒>`（北京时间）走 Telegram 原生定时发送。
- 可校验剧本、清除群内定时任务、任务进度管理；群里禁媒体自动降级为文字；可选转发非任务账号的发言（默认关）。
- MCP 新增 `tg_script_replay`（工具总数 53 → 54）。
- 未在真实 Telegram 环境验证。

## 四、便携版更简洁
- 免安装版解压后顶层只有「双击启动.bat」、辅助脚本和使用说明，程序文件都收进 `app` 文件夹。

## 五、修复
- 采集完成后提示「采集到 0 人」、新手任务「采集一批目标用户」打不上勾。
- 窗口标题和侧栏显示完整版本号（如 v5.0.3），方便分辨小版本。

> 说明：以上在自动化测试和离屏界面里验证过，未在真实 Telegram 账号上逐项验证。
