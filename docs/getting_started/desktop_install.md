## 二、Windows 极速安装步骤

1. 下载 `WhiteCat-TG-Assistant-Commercial-v4.1-Windows.zip`；
2. 解压到非系统盘（推荐解压至 `D:\WhiteCat-TG-Assistant` 等不含中文空格的纯英文路径）；
3. 双击解压目录下的 `WhiteCat-TG-Assistant.exe` 启动程序；
4. 若需要配置 AI Agent 联动，直接双击运行目录下的 `一键配置本机所有AI_Agent.bat`。

---

## 三、macOS 快速安装步骤

1. 下载对应芯片架构的 `.zip` 压缩包并双击解压；
2. 将解压出来的应用程序拖入 `Applications (应用程序)` 文件夹；
3. **初次打开安全提示**：如遇到 macOS 提示“无法打开，因为无法验证开发者”：
   - 打开【系统设置】➔【隐私与安全性】；
   - 滚动到底部，找到被拦截的应用提示，点击【仍要打开】即可正常启动；
4. 若需配置 AI Agent 联动，双击运行目录下的 `一键配置本机所有AI_Agent.command`。
