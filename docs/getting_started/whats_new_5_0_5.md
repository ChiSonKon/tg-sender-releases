# 🆕 v5.0.5 更新说明

> 5.0.4 的功能请看 [v5.0.4 更新说明](whats_new_5_0_4.md)。（本版本含 Windows 与 macOS Apple 芯片；macOS Intel 暂无新包，仍为 5.0.1。）

## 一、更新不再「悄悄失败」
- Windows 点「立即更新」后软件退出又重新打开仍是旧版本，原因通常是有别的程序（AI Agent 通过 MCP 启动的后台实例、另开的软件窗口）占着安装目录里的文件。现在安装包会先结束它们再替换文件，点「立即更新」时会先提示并让你确认，更新失败下次启动会如实说明原因。
- 从 5.0.3 / 5.0.4 升级到 5.0.5 时，请先关闭软件和所有 AI Agent，或直接手动运行下载好的安装包。

## 二、统一采集：新增群组频道采集
- 采集页顶部切换「成员采集」（原功能）与「群组频道采集」：按关键词到搜索机器人（默认 @jisou / @soso / @L9Bot，可自己添加）和 Telegram 搜索里找公开群组 / 频道，可复制 / 导出 / 带去目标分类。

- 采集 / 分类 / 搜索时自动弹出**独立的结果窗口和实时动态**（可搜索、按类型筛选、全选、复制、导出，选中后带去分类 / 私信 / 批量加群）；群组频道搜索新增并发线程。

## 三、目标分类升级
- 名字过滤（关键词可自定义，同名重复自动过滤）、全选 / 复制 / 导出；账号被限流时自动换号，未处理的目标可一键重试；修复筛选按钮显示空白。

- 滚轮不再误改数值：鼠标只是滑过数值框 / 下拉框 / 滑块时，滚轮只滚动页面；点进去后才调值。

## 四、缓存释放
- 设置 → 界面与性能：一键清理账号 Session 的缓存和临时文件（不动登录凭证，在用的账号自动跳过，释放空间实测）。

## 五、炒群夜间慢速
- 剧本回放和 AI 炒群都可设夜间时段（北京时间）与每条间隔（如凌晨 1-7 点每 3-5 分钟一条）。

## 六、MCP
- 新增 `tg_search_groups`、`tg_cache_cleanup`，共 56 项；`tg_classify_targets` 新增 `apply_name_filter`，`tg_script_replay` 新增 `night_slow`。

> 说明：以上在自动化测试里验证过，未在真实 Telegram 账号上逐项验证（搜索机器人的回复格式与翻页、官方搜索、限流轮换等）；请先用少量关键词试一轮。
