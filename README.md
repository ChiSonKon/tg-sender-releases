## 🎯 核心业务一：关键词实时群监控 × 商机信誉风控

解决行业最大痛点：**“公域商机转瞬即逝刷屏漏看？同行诈骗、老赖钓鱼账号防不胜防？”**

系统提供 7×24 小时无人值守实时监控，一旦目标公开群或私密群内有人发布指定业务关键词，毫秒级捕获并自动完成信誉风险初筛！

<p align="center">
  <img src="./docs/promo/02_lead_monitor.png" alt="实时商机监控：命中词高亮、风控黑名单标签与转化流水线（演示数据）" width="98%" />
</p>

### ✨ 核心功能亮点：
1. **0 秒级关键词极速监听**：支持同时配置多个监控规则与多组触发词（如“求购”、“报价”、“现货”、“承兑”、“换汇”等），群内有人发言系统毫秒级捕获弹窗；
2. **独家风控黑名单库比对**：内置本地风控黑名单数据库，支持单条与多行文本批量导入恶意账号。发信人若命中黑名单直接醒目标红告警（如：`⚠️ [跑分老赖] 张三`）；
3. **🛡️ 仅导出白名单(剔除高危)**：导出商机线索时毫秒级自动比对黑名单库，**一键剔除高危、被封或黑名单人员**，仅保留 100% 纯净高意向客户；
4. **指定担保公群信誉核验**：突破 Telegram 隐私壁垒，底层异步权限探针秒级核验陌生发信人是否在权威担保公群内，彻底杜绝虚假冒充；
5. **监控账号在线心跳维持**：消息处理流中自动维护监控账号的在线活跃状态，确保监听不中断。

## 🚀 核心业务二：万人大群成员精准采集 × 拟真群发与私信

解决行业获客痛点：**“不知道精准客户在哪？手动一个个私信效率低且容易被封号？”**

系统打造了集“大群活跃潜客深度挖掘”与“多账号拟真人并发触达”于一体的流水线引擎：

<p align="center">
  <img src="./docs/promo/03_voice_outreach.png" alt="私信触达：电话唤醒、原生语音条与发送队列（演示数据）" width="98%" />
</p>

### ✨ 核心功能亮点：
1. **万人大群毫秒级高并发采集**：直接输入目标行业群链接，高并发抓取成员数据，智能过滤 3 个月未上线的僵尸号、空号与 Bot，导出干净的 CSV / TXT 名单；
2. **高意向最近发言人定向提取**：不仅能抓取成员列表，更能按时间倒序抓取目标群最近发过言的**真实高活跃高意向潜客**，触达转化率提升数倍；
3. **私信群发 & 群组群发双轨并行**：支持多账号矩阵并发私聊客户，或在多个目标群内定时定向广播业务通告；
4. **全类型富文本与多媒体附件**：支持 HTML 排版超链接、图文混排、视频附件、文件资料直接发送，支持频道消息一键转发广播；
5. **全套工业级防封控策略**：
   - 随机发信间隔与批量休息策略，拟真人类操作轨迹；
   - 账号权限状态实时探测，精准识别群内禁言、双向受限（SpamBlock）、冻结与失效；
   - 一键呼起官方 `@SpamBot` 自动化申诉，智能解析提取 UTC 精确解封时间；
   - 私信自动回复引擎，客户回消息即刻承接，无需人工守候。

## 🤖 核心业务三：AI 矩阵智能炒群 × 社群活跃转化运营

解决社群运营痛点：**“新社群冷启动死气沉沉无人发言？推销广告生硬缺乏真实客户信任背书？”**

系统搭载了自研 AI 矩阵炒群引擎，联动多马甲账号根据行业场景自动暖群、抛砖引玉、角色扮演与好评烘托，把公域引流进来的客户快速促成转化！

### ✨ 核心功能亮点：
1. **冷启动群组画像分析**：AI 大模型自动阅读群聊背景与产品设定，一键生成符合垂直行业调性的炒群剧本与多角色马甲人设；
2. **多账号拟真人对话与表情互动**：多马甲账号分工扮演行业专家、新老顾客、询价买家等角色，自动有序跟帖探讨，配合 Emoji Reaction 表情点赞互动；
3. **热启动记忆提炼与上下文承接**：系统自动沉淀群内历史话题记忆，真实潜客一旦在群内插话提问，AI 马甲自然承接引导，毫无生硬违和感；
4. **目标群画像 1:1 毫秒级克隆伪装**：一键抓取目标群或行业领袖的真实头像、个性昵称、个人简介，全自动同步至矩阵马甲账号；
5. **53 项 MCP 智能体接管（5.0.1 起；5.0.0 为 45 项）**：率先全面支持 Anthropic Model Context Protocol。不管是 Claude、Cursor 还是 Google Antigravity，发送一句话即可由 AI 接管获客！
